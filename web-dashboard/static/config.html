🌐 外部接続 Central NAT (NAT_ENABLED)
MAP-E (mpe-common) および PPPoE クライアントからの IPv4 トラフィックを、管理インターフェース (MGT_IF) 経由で外部ネットワークへ NAT (MASQUERADE) 接続します。
🌐 接続方式別 VLAN 番号設定
接続を有効にする VLAN 番号を指定します。スペース区切りで複数指定可能です。
※ 不要な方式は空欄（省略）にすることで、関連するサーバーコンテナの起動を抑止できます。
ひかり電話なし動的 IPv4 (SLAAC WAN)
ひかり電話あり動的 IPv4 (DHCPv6-PD)
ひかり電話なし固定 IPv4 (SLAAC固定)
ひかり電話あり固定 IPv4 (DHCPv6-PD固定)
PPPoE 専用の収容 VLAN 番号（MAP-E 用の VLAN は自動的に合算されます）

各 VLAN サブインターフェースの親となる物理NIC
スペース区切りで複数指定。chrony.conf の server 行に反映されます。
⚡ PPPoE サーバー & クライアント認証設定
サービス（インスタンス）ごとに提供する収容 VLAN、接続を許可するクライアント認証アカウントや固定IP/サブネット委任を設定します。
1. PPPoE サービス定義
※ 接続を受け付ける PPPoE サービス名（半角英数字/_- 最大11文字）と閉域 VRF の有効/無効を定義します。PPPoE はすべての回線 VLAN で共通して提供され、サーバー IP はセッションごとに動的に割り当てられます。
サービス名 (最大11文字) 閉域 VRF 操作
2. PPPoE クライアント登録
ユーザー名 パスワード 割当 IP / サブネット (空欄/* でプール) サービス名 IPv4 DDNS ホスト名 備考 操作
💡 書式: ユーザー名, パスワード, 割当IP, サービス名, DDNSホスト名(任意), 備考(任意)
※ カンマ(CSV)、タブ(Excelからの貼り付け)、半角スペース区切りのいずれも自動認識します。行頭 # や空行はコメントとして扱われます。サービス名未指定時は * となります。

🔧 詳細設定（サーバー IP / IP プール） ▶
サーバーローカルIP自動採番時のベースアドレス
固定IPを指定しないユーザー（IP欄を * または空欄に設定）へ払い出す IP プール（CIDR 形式）。
空欄の場合はプール払い出しが無効となり、全ユーザーに固定IPが必要になります。
🔗 IPoE (MAP-E) 共通パラメータ設定
Border Relay (BR) およびプロビジョニングサーバーで共通して使用する IPv4/IPv6 パラメータと固定IP・端末備考・DDNS設定です。
動的クライアント（SLAAC動的 / DHCP-PD動的）へ払い出す IPv4 プール（CIDR表記）
💡 固定IP・端末備考および DDNS（ホスト名）の登録について
・固定 IP を割り当てる場合: VLAN 番号（例: 841）または MAC アドレスと 固定 IPv4 アドレス（例: 192.168.200.1/32）を入力します。
・動的 IP のまま備考や DDNS を登録する場合: 固定 IPv4 アドレスを空欄のまま入力してください（動的IP扱いとなります）。
・DDNS ホスト名: DNS に自動登録するホスト名（例: cebox1.p-ns.flets-west.jp）を入力します（空欄可）。

📡 MAP-E (SLAAC) 設定
ℹ️ SLAAC 動的 IP について（個別設定不要）
CE（端末ルーター）は radvd が広告する IPv6 プレフィックスから自律的に IPv6 アドレスを生成します。
プロビジョニングサーバーが BR_IPV4_POOL と CE IPv6 アドレスから機械的に IPv4 アドレスと PSID を自動算出するため、端末ごとの事前個別設定は一切不要です。
※ 固定 IP や端末備考の登録は「3️⃣ IPoE (MAP-E) 共通」タブで行えます。
🔧 拡張設定（SLAAC IPv6 プレフィックス計算用パラメータ） ▶
📦 MAP-E (DHCP-PD) 設定
ℹ️ DHCP-PD 動的 IP について（個別設定不要）
CE（端末ルーター）が DHCPv6-PD リクエストを送信すると、Kea DHCPv6 のプレフィックスプール（PD_POOL）から空きプレフィックス（/56）が動的に貸し出され、IPv4 と PSID が自動算出されます。
そのため、端末ごとの事前個別設定は一切不要です。
※ 固定 IP や端末備考の登録は「3️⃣ IPoE (MAP-E) 共通」タブで行えます。
