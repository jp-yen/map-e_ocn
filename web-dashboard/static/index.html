📡 MAP-E (SLAAC) 設定


          
          

            
ℹ️ SLAAC 動的 IP について（個別設定不要）

            CE（端末ルーター）は radvd が広告する IPv6 プレフィックスから自律的に IPv6 アドレスを生成します。

            プロビジョニングサーバーが BR_IPV4_POOL と CE IPv6 アドレスから機械的に IPv4 アドレスと PSID
            を自動算出するため、端末ごとの事前個別設定は一切不要です。

            ※ 固定 IP や端末備考の登録は「3️⃣ IPoE (MAP-E) 共通」タブで行えます。

📦 MAP-E (DHCP-PD) 設定


          
          

            
ℹ️ DHCP-PD 動的 IP について（個別設定不要）

            CE（端末ルーター）が DHCPv6-PD リクエストを送信すると、Kea DHCPv6 のプレフィックスプール（PD_POOL）から空きプレフィックス（/56）が動的に貸し出され、IPv4
            と PSID が自動算出されます。

            そのため、端末ごとの事前個別設定は一切不要です。

            ※ 固定 IP や端末備考の登録は「3️⃣ IPoE (MAP-E) 共通」タブで行えます。
