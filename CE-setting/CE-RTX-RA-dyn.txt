=============================================================================
RTX1210 設定例: OCN MAP-E (SLAAC 動的IP / VLAN4)
  機種: RTX1210 Rev.14.01.42
=============================================================================

--- 1. 基本・管理設定 ---
login user yama_yama haha_haha
console columns 4096
console lines infinity
console prompt RA-dyn

--- 2. LAN / DHCP サーバー設定 ---
ip lan1 address 192.168.10.1/24
ip lan2 address 192.168.20.1/24

dhcp service server
dhcp server rfc2131 compliant except remain-silent
dhcp scope 1 192.168.10.100-192.168.10.200/24

--- 3. WAN (LAN3) IPv6 / NGN / DNS 設定 ---
ipv6 routing on
ipv6 prefix 1 ra-prefix@lan3::/64
ipv6 source address selection rule lifetime
ipv6 lan3 address auto
ipv6 lan3 dhcp service client ir=on
ngn type lan3 ntt
dns server dhcp lan3

--- 4. MAP-E トンネル・ルーティング設定 ---
ip route default gateway tunnel 1
tunnel select 1
 tunnel encapsulation map-e
 tunnel map-e type ocn
 ip tunnel mtu 1460
 ip tunnel tcp mss limit auto
 ip tunnel nat descriptor 1
 tunnel enable 1
tunnel select none

--- 5. NAT 設定 (MAP-E ポート制限対応) ---
nat descriptor type 1 masquerade
nat descriptor address outer 1 map-e

--- 6. 時刻同期 (SNTP クライアント) 設定 ---
schedule at 1 startup * ntpdate 2400:4150:99::123
schedule at 2 */* 04:00 * ntpdate 2400:4150:99::123

即時で時刻合わせする場合:
RA-dyn# ntpdate 2400:4150:99::123
2026/11/26 02:01:23  -1second

参考: 商用フレッツ網の NTP (SNTP) サーバー例
  NTT東日本: 2404:1a8:1102::a / 2404:1a8:1102::b
  NTT西日本: 2001:a7ff:102::a / 2001:a7ff:102::b / 2001:a7ff:102::c

オプション: IPoE (MAP-E) と PPPoE の併用設定
=============================================================================

--- 1. PPPoE インターフェース設定 (pp 1) ---
※ DNS は IPoE 側 (dns server dhcp lan3) を使うため ppp ipcp msext on は外す
   (有効にすると IPCP 経由の DNS 100.127.255.255/32 が PP[01] 向きの一時経路になり
    MAP-E 側の BR 宛て ping 等が PPPoE 側へ吸われるため)
pp select 1
 pp always-on on
 pp keepalive use lcp-echo
 pppoe use lan3
 pppoe auto disconnect off
 pp auth accept chap pap
 pp auth myname user-ocn@one.ocn.ne.jp ocn
 ppp lcp mru on 1454
 ppp ipcp ipaddress on
 ppp ccp type none
 ip pp mtu 1454
 ip pp tcp mss limit auto
 ip pp nat descriptor 2
 pp enable 1
pp select none

※ PPPoE の Service-Name を指定する場合は pp select 1 内に以下のように記載:
pppoe service-name OCN

--- 2. PPPoE 用 NAT 設定 (ディスクリプター 2) ---
nat descriptor type 2 masquerade
nat descriptor address outer 2 ipcp

--- 3. 経路振り分け例 (デフォルトは MAP-E、特定宛先のみ PPPoE) ---
ip route default gateway tunnel 1
ip route 203.0.113.0/24 gateway pp 1

※ 将来 PPPoE 側の DNS (dns server pp 1) を併用する場合のみ以下を追加:
dns private address spoof on
